# Transparency & Disclosure Guidelines for AI Use

**Version:** 1.0 | **Date:** June 2026 | **Owner:** Lead DevOps & AI Ethics Officer
**Classification:** Internal Use Only | **Review Cycle:** Quarterly

---

## 1. Disclosure Levels

| Level | Scenario | Required? |
|---|---|---|
| **L1 — Internal** | AI used for personal productivity | Not required |
| **L2 — Team** | AI-generated code committed to shared repos | **Yes — in PR** |
| **L3 — Client** | Deliverables with AI-generated content | **Yes — in delivery notes** |
| **L4 — Public/Users** | Customer-facing AI features | **Yes — in UI / ToS** |

---

## 2. L2: Pull Request Disclosure

All PRs containing AI-generated or AI-significantly-assisted code must include:

```markdown
## AI Assistance Log

| Field | Details |
|---|---|
| **Tool used** | Claude Sonnet 4.6 / Claude Code |
| **Scope** | e.g., "Generated the MongoDB aggregation in analytics.service.ts" |
| **Human review** | ✅ Reviewed, tested locally, edge cases considered |
| **Extra scrutiny needed** | e.g., "Error handling in payment flow — review carefully" |
```

**What counts as "AI-significantly-assisted":**
- AI wrote >30% of a file
- AI generated the module structure or architecture
- AI wrote security-sensitive sections (auth, encryption, validation)
- AI wrote any user-facing copy

You do **not** need to disclose: auto-complete suggestions, using Claude to explain code, or information lookups.

**Commit message convention:**
```bash
git commit -m "feat: add order webhook signature validation middleware [ai-assisted]"
```

---

## 3. L3: Client Deliverables

**In delivery notes / handover emails:**
```
Note on AI-Assisted Development:
Parts of this delivery were developed with AI assistance (Claude, Anthropic).
All AI-generated content has been reviewed, tested, and approved by our senior
development team. Human accountability remains with [Lead Developer Name].
```

**In technical documentation headers:**
```
> Drafted with AI assistance (Claude, Anthropic, June 2026) and reviewed by [Name], [Role].
```

**Before starting an engagement:** Check the client's contract for AI tool restrictions. If no AI clause exists, disclose your intended use in writing upfront.

---

## 4. L4: Customer-Facing Features

For product features where Claude's output reaches end users:

**Minimum UI disclosure:**
```html
<span class="ai-badge" title="Generated by AI, reviewed by our team">AI-assisted</span>
```

**Terms of Service:** If AI is used in personalisation or automated decisions, your ToS must state that AI tools are used and that no personal identifying data is sent to external AI services without consent. Consult Legal before drafting.

---

## Quick Reference

```
Audience       → Disclosure required
You only       → None
Your team      → PR description: AI Assistance Log
A client       → Delivery note: AI assistance + human review statement
End users      → UI badge + ToS clause

When in doubt: disclose. Over-disclosure is always safer.
```
